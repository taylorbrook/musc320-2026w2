# MUSC 320 Computer Music: course repo

Patches, starter code and browser demos for MUSC 320, UBC Winter Term 2 (Jan to Apr 2027). Class prep, due dates and submissions are on Canvas: https://canvas.ubc.ca/courses/198375

## What is in here

- `setup/`: the week 1 audio check.
- One folder per class meeting, named like its Canvas module, from `wk01-wed-hello-max/` to `wk13-fri-final-lab/`.
- `troubleshooting/`, `assignments/` and `final/`: starter files, added on their release dates.
- `demos/`: the browser demos used on Canvas pages.
- `my-work/`: your own work. Git ignores it.

## Before every class

1. Open GitHub Desktop and choose this repo.
2. Click **Fetch origin**, then **Pull origin**.
3. Open today's folder.

## The my-work rule

Never change files in the course folders. Before you change anything, copy the whole session folder into `my-work/` and work on the copy. The copy keeps its sibling files, so the patches still open. Git ignores `my-work/`, so your work never blocks a pull.

## If Pull refuses

1. In GitHub Desktop, choose **Branch**, then **Stash all changes**.
2. Click **Pull origin**. Nothing is lost, and you can restore the stash later.

If a pull is interrupted, click **Pull origin** again.

Last resort: copy your `my-work/` folder somewhere safe, delete the clone, and clone again.

## No Git?

Download everything as a ZIP: https://github.com/taylorbrook/musc320-2026w2/archive/refs/heads/main.zip

Download it again each week, and keep your own work outside the unzipped folder.
